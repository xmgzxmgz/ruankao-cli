# ruankao-test-runner

终端刷题器，低调模式 —— 外观像在跑单元测试 / 看构建日志，实际上在刷软考**信息系统项目管理师（高项）**题。

零依赖：仅需 Python 3 标准库，不联网、无弹窗、纯键盘。

## 截图

![screenshot](screenshot.png)

## 快速开始

```bash
python drill.py              # 随机练全部 40 题
python drill.py --cat 计算   # 只练计算题（33 个分类任选）
python drill.py --wrong      # 只复习错题本，答对自动移出
python drill.py --list-cats  # 列出所有分类
python drill.py -v           # 版本
```

### 交互命令

| 输入 | 作用 |
|---|---|
| `a/b/c/d` 或 `1/2/3/4` | 作答 |
| `n` | 跳过本题（不判分） |
| `w` | 查看错题本 |
| `r` | 重做当前题 |
| `h` | 帮助 |
| `q` | 退出（自动把错题写入 `wrong.json`） |

结束会打印 session summary（答题数 / 通过 / 失败 / 正确率）。

## 题库

`questions.json`，字段：

```json
{
  "id": 1,
  "cat": "分类",
  "q": "题干",
  "opts": ["A. ...", "B. ...", "C. ...", "D. ..."],
  "ans": 0,
  "exp": "解析"
}
```

`ans` 为正确选项索引（0=A,1=B,2=C,3=D）。自行增删题即可，保存后重跑生效。

> 题库基于高项考纲与公开真题考点整理生成（参考 xiaomabenten/ruankao_itpm 备考库、希赛/软考吧历年真题），非官方题库，仅供练习。

## 隐蔽使用建议（上班摸鱼专用）

- **改名**：把 `drill.py` 改成 `run_tests.py` / `devkit.py` / `logscan.py` 之类，和项目代码放一起。
- **配色**：终端用深色背景，启动时像测试套件加载；纯键盘交互，没有花哨窗口。
- **分屏**：和编辑器/终端并排，盯着像在跟构建日志较劲。
- **全局命令**：把 `.local/bin` 加入 PATH 后，任意目录输入 `ruankao` 即可启动。
